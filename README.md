# Agents Hub

مشروع محلي لإدارة مجموعة من الوكلاء عبر واجهة عربية وطبقة تنسيق Maestro.

## حالة الرفع

هذه أول نسخة مصدرية من الأرشيف المحلي بعد تنظيفها للنشر العام. الأرشيف المضغوط محفوظ على هيئة أجزاء Base64 داخل `.upload/`. اجمع الأجزاء بالترتيب ثم فك ترميزها:

```sh
cat .upload/agents-hub-source.tar.gz.b64.part-* | base64 -d > agents-hub-source.tar.gz
tar -xzf agents-hub-source.tar.gz
```

## ما تم استبعاده

- قاعدة بيانات SQLite وملفات WAL/SHM.
- السجلات وملفات PID وPython bytecode.
- مسارات Termux الشخصية في `agents.json`؛ استُبدلت بمسارات نسبية.
- رموز PNG؛ أبقينا أيقونة SVG وعدّلنا manifest وservice worker.

## تعديلات السلامة

- إزالة رمز المصادقة الافتراضي و`dev-bypass`؛ التحقق يفشل مغلقًا عند غياب `HUB_AUTH_TOKEN`.
- إضافة `.env.example` دون أسرار.
- إضافة `SECURITY.md` لتوثيق المخاطر المعروفة.

**تحذير:** هذه النسخة ليست جاهزة للنشر العام. بعض نقاط القراءة وWebSocket لا تطبق المصادقة بصورة موحدة، وCORS واسع افتراضيًا، وتشغيل الوكلاء يستخدم `shell=True`. لا تشغّلها على شبكة عامة قبل معالجة هذه المخاطر وإضافة اختبارات فعلية.
