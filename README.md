# Serag Agent OS

منظومة تنسيق مستقلة لأكاديمية السراج: مدير رئيسي وستة وكلاء متخصصين. هذا الإصدار هو **نواة تشغيل محلية أولية** وليس نظاماً إنتاجياً أو تكاملاً مع Moodle.

## الوكلاء
- `serag_master`: استقبال المهام وتوجيهها ومتابعة حالتها.
- `administrative`: الشؤون الإدارية.
- `academic`: المحتوى والتقييم والشؤون الأكاديمية.
- `operations`: التشغيل والجداول والدعم.
- `marketing_sales`: التسويق والمبيعات.
- `finance`: الميزانيات والفواتير والتقارير المالية.
- `quality_analytics`: الجودة والتحليل وقياس الأداء.

## مبادئ السلامة
- لا يوجد تنفيذ أوامر نظام أو `shell=True`.
- لا توجد مفاتيح API أو أسرار داخل المستودع.
- أي نشر أو كتابة خارجية أو إجراء مالي أو تغيير في Moodle يتطلب موافقة صريحة.
- لا ينفذ الوكيل مهمة إلا إذا كانت قدرته مسجلة ومصرحاً بها.
- كل انتقال حالة يسجل في سجل تدقيق مترابط ببصمة SHA-256.
- التخزين في هذا الإصدار داخل الذاكرة فقط؛ لا تستخدمه كخدمة إنتاجية.

## التشغيل والاختبار
يتطلب Python 3.11 أو أحدث:

```bash
python -m pip install -e ".[dev]"
pytest
```

مثال استخدام:

```python
from serag_agent_os import SeragOrchestrator, TaskRequest

os = SeragOrchestrator.default()
task = os.submit(TaskRequest(
    title="إعداد تقرير حضور أسبوعي",
    description="حلّل بيانات الحضور المتاحة وقدّم ملخصاً",
    capability="attendance_reporting",
    risk="low",
))
result = os.run(task.id)
print(result.status, result.result)
```

## حدود الإصدار
لا يتضمن هذا الإصدار نموذج ذكاء اصطناعي أو اتصالاً فعلياً بـ Moodle أو البريد أو بوابات الدفع أو WhatsApp. الوكلاء معرفون بصلاحياتهم، ويُمرر التنفيذ إلى معالجات محلية يتم تسجيلها صراحة. يلزم قبل الإنتاج إضافة قاعدة بيانات دائمة، مصادقة، إدارة أسرار، مراقبة، اختبارات أمنية، وربط Moodle في بيئة تجريبية.
